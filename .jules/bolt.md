## 2024-10-25 - Bulk Insert Opt for Quiz Questions
**Learning:** Found an N+1 query issue in the Quiz Generation service (`src/services/quiz.ts`) where questions were created one-by-one inside a transaction loop. Switching to `tx.quizQuestion.createMany` required careful mocking setup in Vitest `$transaction` mocks since `createMany` is not automatically stubbed out like `create`. Additionally, when using `createMany` with JSON typed fields like `options`, mapping `as unknown as Prisma.InputJsonValue` is strictly required to satisfy typechecks in Prisma 7.
**Action:** Always check `createMany` applicability for AI pipelines that generate arrays of entities (like questions or topics). When doing so, proactively update the Prisma `createMany` mocks in the test files (`$transaction` wrapper) to ensure test stability, and cast JSON structures explicitly.
