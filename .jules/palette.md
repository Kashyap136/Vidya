## 2024-06-25 - Improved Accessibility for Custom Role="button" Components
**Learning:** Custom interactive components utilizing `role="button"` require comprehensive keyboard accessibility implementations beyond standard click handlers. Without explicit `.preventDefault()` in `onKeyDown` handlers for Space/Enter keys, default browser actions (like scrolling) disrupt the user experience. Additionally, explicitly defining `focus-visible` classes, dynamic `tabIndex` states (`-1` when disabled), and `aria-disabled` are crucial to emulate native button accessibility and behavior for screen readers and keyboard users.
**Action:** Always include `.preventDefault()` for Enter/Space keys, define explicit `focus-visible` styling (using Tailwind classes like `focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2`), and apply `aria-disabled` and dynamic `tabIndex` to all custom `role="button"` elements.
