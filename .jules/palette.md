## 2024-05-18 - [Custom Buttons Need Keydown PreventDefault]
**Learning:** When creating custom interactive elements with `role="button"` (like a drag-and-drop upload zone), simply calling `onClick` in the Space/Enter `onKeyDown` handler is insufficient; without `e.preventDefault()`, the Spacebar triggers the default browser behavior (scrolling the page), ruining the keyboard user experience. Additionally, these elements often lack built-in focus styling unless explicitly added.
**Action:** Always include `e.preventDefault()` for Space/Enter in `onKeyDown` handlers on custom interactive elements to suppress default browser actions, explicitly add a `focus-visible` ring so focus is trackable by keyboard users, and use `aria-disabled` and `tabIndex={-1}` for proper disabled state announcements and focus management.
