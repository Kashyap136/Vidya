## 2024-10-04 - Input component accessibility and tab index
 **Learning:** Using `tabIndex={-1}` on buttons or internal interactive elements of custom inputs (like a password visibility toggle) completely breaks keyboard navigation and makes them inaccessible to keyboard-only and screen reader users. Additionally, internal clear actions (like a search bar) should have an explicit 'Escape' keyboard shortcut that conditionally calls `e.stopPropagation()` and clears the input only if a value exists.
 **Action:** Allow the browser's default focus order to apply instead of using `tabIndex={-1}`. For interactive components with internal clear actions, implement explicit 'Escape' shortcuts and ensure the clear button has `type='button'` to prevent unintended form submissions, and include explicit `focus-visible` UI states.
