## 2024-05-18 - Immediate Visual Feedback for Async Toggles
**Learning:** Users can perceive the UI as unresponsive when toggling state (like completing a topic or task) takes time without immediate visual feedback. Adding a loading spinner (`Loader2` from `lucide-react`) directly on the toggle button itself during the `isPending` state significantly improves perceived performance and prevents duplicate clicks. Furthermore, ensuring interactive elements like these icon buttons have proper `focus-visible` styling (using `ring` utilities) is crucial for keyboard navigation accessibility.
**Action:** When implementing async toggle actions on icon buttons (like checkboxes), always use a `useTransition` hook and render a loading spinner during the `isPending` state. Additionally, always ensure robust keyboard focus styles using classes like `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2 disabled:opacity-50 transition-opacity`.
