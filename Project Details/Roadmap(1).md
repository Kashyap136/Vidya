# 6. MVP (Minimum Viable Product)

Objective

Validate the core idea.

Core Features

✓ Authentication

✓ Dashboard

✓ Upload PDF

✓ PDF Text Extraction

✓ AI Topic Generation

✓ Study Plan

✓ Progress Tracking

✓ AI Chat

✓ Resource Recommendations

✓ Responsive UI

Out of Scope

- Flashcards
- Voice Tutor
- Mobile App
- Teacher Dashboard
- Parent Dashboard

Success Criteria

- Students can upload a syllabus.
- AI generates structured topics.
- Study plan is usable.
- Dashboard displays progress.

# Product Principles

Every new feature should answer:

1. Does it reduce confusion?

2. Does it improve learning?

3. Does it save time?

4. Is it worth maintaining?

If the answer to most of these questions is "No", the feature should not be added.
