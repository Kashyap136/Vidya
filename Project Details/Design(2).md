# 1. Design Philosophy

Vidya should feel like:

- Calm
- Professional
- Student-first
- Modern
- Minimal
- Friendly

The interface should help students focus on studying—not on learning how to use the application.

Every screen should reduce cognitive load.

# 3. Design Principles

Every UI decision should satisfy these principles:

### Simplicity

Do not overload users.

### Consistency

Components behave consistently.

### Accessibility

Every student should be able to use Vidya.

### Feedback

Every action provides feedback.

### Performance

Fast interfaces feel better.

### Theme Adaptability

Every component supports Light, Dark, and System modes.

# 20. Dark Mode

Dark Mode is a Version 1 requirement.

Every component must support:

- Light mode
- Dark mode
- System preference

Dark mode should respect the user's system preference by default with a manual toggle.

Color tokens should use CSS custom properties for seamless theme switching.

# UX Principles

Students should never wonder:

- What happens next?
- Where should I click?
- Is my work saved?
- Why did something fail?

The interface should answer these questions naturally.

---

Every screen must include:

✓ Clear hierarchy

✓ Responsive layout

✓ Loading state

✓ Empty state

✓ Error state

✓ Success state

✓ Accessible controls

✓ Keyboard support

✓ Consistent spacing

✓ Consistent typography

✓ Mobile usability

# Design Philosophy

Good design is invisible.

The student should focus on learning—not on understanding the interface.

Every design decision should reduce friction and increase confidence.
